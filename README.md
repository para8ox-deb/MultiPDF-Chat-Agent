# 📚 MultiPDF Chat-Agent

**Transform your PDF experience with intelligent conversations.**

MultiPDF Chat-Agent is an AI-powered web application that allows users to interact with the content of multiple PDF documents through a conversational interface. Built using **Streamlit**, **Langchain**, **Google Gemini Pro**, and **FAISS**, it enables context-aware question answering and efficient document understanding.

---

## 🚀 Features

- 📂 **Multi-PDF Upload** – Upload and process multiple PDF documents at once.
- 🧠 **Contextual Chat** – Ask questions and receive accurate, document-based answers.
- ⚡ **Semantic Search** – Powered by FAISS for fast and relevant information retrieval.
- 🎯 **Advanced Language Model** – Utilizes Google Gemini Pro for powerful NLP capabilities.
- 🖥️ **Streamlit Interface** – Simple and interactive web interface for ease of use.

---

## 🛠️ Tech Stack

| Component        | Technology           |
|------------------|----------------------|
| Frontend         | Streamlit            |
| Backend Logic    | Langchain            |
| Language Model   | Google Gemini Pro    |
| Vector Store     | FAISS                |
| File Handling    | PyPDF2 / fitz        |

## 📥 Installation

Follow these steps to get started locally:

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Aakash/MultiPDF-Chat-Agent.git
   cd MultiPDF-Chat-Agent

2. **Create a Virtual Environment (Optional but Recommended)**
   ```bash
   git clone https://github.com/Aakash/MultiPDF-Chat-Agent.git
   python -m venv venv
   source venv/bin/activate   # On Windows use: venv\Scripts\activate

3. **Install Dependencies**
   ```bash
   pip install -r requirements.txt

4. **Run the App**
   ```bash
   streamlit run app.py

5. **Open in Browser**
   Streamlit will provide a local URL. Open it to access the app.


## 🧪 Usage
Launch the app.

Upload one or more PDF files.

Ask questions in natural language.

Receive answers based on the content of your uploaded documents.
